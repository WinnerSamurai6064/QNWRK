# QNWRK

A workstation running and deploying code directly from the UI using filesystem and an iframe to view web app them after they build for docker and gradio or are committed if it's static , eliminating the need for SSH 80% of time

live dev mode/logs visible so we can see exactoy what went wrong when a build fails for docker or gradio , we can also commit bash code on a web UI of shell tied to a specific docker project (only if necessary and experimental)
